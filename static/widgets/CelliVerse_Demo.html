CelliVerse

EWCSR-based clustering, marker discovery, and cell-type annotation for single-cell RNA-seq data
R package Single-cell Reference-free v1.0+

CelliVerse is an R package for single-cell RNA-seq analysis built around Expression-Weighted Centered Scaled Ranks (EWCSR). It provides an integrated, reference-free workflow for clustering, marker discovery, purity evaluation, and cell-type annotation.

Core design principles

🧬
EWCSR transformation
Captures within-cell transcriptional structure without parametric assumptions or pre-normalization.
🎯
Data-driven markers
Discovers positive, negative, and medium markers directly from the data without reference atlases.
✅
Purity evaluation
Quantifies marker specificity within clusters to ensure high-confidence biological signals.
🏷
Cell-type annotation
Annotates clusters using curated marker databases or LLM-based inference via typoClust.
📉
Feature selection
Selects globally informative markers for dimension reduction and visualization alternatives to HVG.
⚡
Sketch & transfer
Scales to massive datasets via geometric sketching with label transfer to full data.

clustoCell() Cluster
Unsupervised EWCSR clustering with Leiden community detection, marker discovery, and optional sub-clustering.
Input: Seurat / matrix Output: ClustoCell
clustoCell_TransferLabel() Cluster
Transfers major and sub-cluster labels from a sketched (subsampled) ClustoCell object to the full dataset.
Input: ClustoCell Output: labels
markoClust() Marker
Identifies markers in predefined clusters with optional Leiden sub-clustering.
Input: Seurat / SCE Output: MarkoCell
markoCell() Marker
Ranks positive and negative markers for arbitrary cell subsets or even single cells.
Input: Seurat / SCE Output: MarkoCell
markerPurity() Marker
Quantifies marker purity by evaluating expression specificity within clusters.
Input: Seurat / SCE Output: purity scores
markoClustVis() Viz
Generates faceted dot plots for marker visualization across clusters or sub-clusters.
Input: ClustoCell / MarkoCell Output: ggplot
signatureDotHeatmap() Viz
Dot heatmap summarizing signature-associated feature expression across clusters.
Input: Seurat Output: ggplot
typoClust() Annotate
Annotates clusters using curated marker databases or LLM-based inference.
Input: ClustoCell / MarkoCell Output: TypoClust
typoClustVis() Annotate
Visualizes cell-type annotation results from typoClust.
Input: TypoClust Output: ggplot
addClustoData() Helper
Adds major and sub-cluster labels from ClustoCell to Seurat or SCE metadata.
Input: ClustoCell Output: modified object
addTypoData() Helper
Adds inferred cell-type annotations from TypoClust to Seurat or SCE metadata.
Input: TypoClust Output: modified object
getDatasetMarkers() Helper
Extracts dataset-level positive, negative, and medium markers for dimension reduction.
Input: ClustoCell Output: gene list
featureInspect() Helper
Searches desired features across all marker collections in a ClustoCell object.
Input: ClustoCell Output: search results
