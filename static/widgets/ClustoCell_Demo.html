clustoCell() is the main entry point of the CelliVerse package. It performs unsupervised clustering of single-cell data using Expression-Weighted Centered Scaled Ranks (EWCSR), followed by marker discovery and optional sub-clustering — all directly from raw count data. Step 1: Expression-Weighted Centered Scaled Ranks (EWCSR)

Transforms the raw count matrix into a cell-by-gene matrix of centered, scaled ranks weighted by expression magnitude. This captures relative transcriptional structure without assuming parametric distributions.

EWCSR(i,j) = scale( rank( expr(i,j) ) ) × weight( expr(i,j) )

The transformation preserves within-cell relationships while normalizing across the dataset, making it robust to sequencing depth variation.

Step 2: Leiden Community Detection

Applies the Leiden algorithm to the EWCSR-transformed data to identify clusters that maximize intra-cluster similarity while preserving biological coherence.

Resolution → modularity optimization → cluster labels

Leiden is preferred over Louvain for its guarantee of well-connected communities and faster convergence.

Step 3: Marker Discovery

For each cluster, identifies genes that are:

  • Positive markers: Highly expressed in the target cluster vs. all others
  • Negative markers: Depleted in the target cluster
  • Medium markers: Moderately specific features

Step 4: Optional Sub-clustering

Recursively applies the same pipeline within major clusters to detect finer sub-populations. Sub-clusters inherit the parent cluster markers and generate their own specific signatures.

The function returns a ClustoCell S4 object with the following structure:

├─ clusters list Major & sub-cluster labels per cell
├─ major factor Cell → major cluster assignment
└─ sub factor Cell → sub-cluster assignment
├─ markers list Cluster-specific marker collections
├─ positive list High-specificity markers per cluster
├─ negative list Depleted markers per cluster
└─ medium list Moderate markers per cluster
├─ quiescent_cells character Cell IDs with no high markers (inactive/resting)
├─ globally_pure_ranked character Top globally informative features
├─ globally_pure_high character High-purity features across dataset
└─ globally_pure_medium character Medium-purity features across dataset
